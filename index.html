Terminal

1. Install it (once). Claude downloads it for you, no git needed

claude "install github.com/js-commit/video-editing-skills to ~/video-editing-skills"

2. Cut your first video. The first time, it offers a quick setup

cd ~/video-editing-skills && claude "cut the retakes out of ~/Movies/my-take.mp4"

Needs Claude Code (a plan with Claude Opus), Python 3 and ffmpeg. DaVinci Resolve is optional. Your video files stay on your computer.
